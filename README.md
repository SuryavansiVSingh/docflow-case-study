# DocFlow — case study

**Live page:** https://suryavansivsingh.github.io/docflow-case-study/

DocFlow is an AI document inbox: invoices and receipts that arrive by email are safety-checked, read (fixed rules + AI for photos and unusual layouts), validated (net + VAT = total, dates, duplicates) and delivered to Excel or Google Sheets, with a review screen for anything doubtful.

This repository only holds the public case-study page. The source code is private; available on request.

All companies and documents shown are fictional.
